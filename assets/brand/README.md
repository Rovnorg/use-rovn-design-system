# Original Rōvn mark

`rovn-lockup.svg` retains the exact path geometry and viewBox from the first SVG
in `design/paper/selected/OC9-0.jsx`, sourced from Jerry's public repository at
`f00d0183e6353d5953c2a4a7dca700c68da1a5b1`.

The single source path is split at the first symbol subpath (`M176.335`) to permit
an amber symbol and ink wordmark without changing any coordinates. JSX-only
attributes were removed and the original warm-white fill was replaced with current
brand colors. The captured source/reference assets remain unchanged.

Keep the original identity, proportions and project-use scope. This extraction
is not a newly licensed third-party logo or a grant of additional trademark rights.
