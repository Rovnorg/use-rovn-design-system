# Course pack improvement proposal

## Objective

Prepare one coordinated course pack from the client's supplied, approved material. This is a fictional proposal used to test document layout. It is not an offer from Rōvn and creates no commitment.

The proposed outcome is a participant guide, facilitator guide and operating checklist that use the same approved facts while serving different readers. The participant guide supports learning. The facilitator guide supports delivery. The checklist supports repeatable preparation.

## Scope and deliverables

| Deliverable | Included work | Acceptance evidence |
| --- | --- | --- |
| Source inventory | Identify supplied files, owners, conflicts and required outputs | Every source has a recorded status |
| Participant guide | Organise approved explanation and exercises | Content complete and readable |
| Facilitator guide | Organise supplied timing and delivery notes | Notes align with the participant guide |
| Operating checklist | Present supplied preparation steps | Each step has a clear action |

The example scope excludes new course content, legal advice, accreditation and changes to assessment policy. Any requested scope change would need a separate, explicit description before work could be agreed.

## Responsibilities

The example delivery team prepares the source map, layouts and quality record. The customer supplies current materials, identifies the content owner and reviews meaning. Conflicting instructions remain open until the named owner resolves them. The renderer cannot resolve a policy disagreement through formatting.

## Acceptance and handover

Acceptance requires the supplied content to be present, references to work, tables to remain readable and editable outputs to contain real text and tables. Handover includes the source model, exported files, source mapping and unresolved limitations.

The next step in this fictional process is a scope review. A layout acceptance block is not a signature, an executed agreement or approval to send this proposal externally.
