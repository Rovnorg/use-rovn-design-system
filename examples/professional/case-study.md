# Context

An imaginary training team needed a one-page decision memo, a longer plan, and an agreement reference. Its report template gave every file the same cover and section treatment. This case illustrates the review method, not a measured customer outcome.

# Intervention

The team classified each file by its reader's task. The memo led with the decision, the plan separated assumptions from evidence, and the agreement reference preserved clause labels in a conventional text flow.

Authors kept the original source beside the rendered file. Reviewers checked text extraction and page images separately, because either check alone could miss a defect.

# Illustrative observations

| Question | What the fictional team would inspect |
| --- | --- |
| Is the purpose clear? | First-page title, recommendation and next action |
| Is the source intact? | Exact names, numbers, qualifications and links |
| Is it editable? | Native paragraphs, table cells and formula cells |
| Is it ready to share? | Review findings, approvals and destination |

# Limits and lesson

No customer interviews, time savings, adoption results, or revenue measurements underpin this example. Its lesson is procedural: select the document's structure first, then verify the actual file. A future case study would need named evidence, permissions, dates, and a defensible method before reporting results.
