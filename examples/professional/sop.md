# Purpose and scope

Use this procedure to prepare a reviewed PDF and its editable source for an internal handoff. It applies to synthetic training documents only. It does not authorize external publication, legal execution, or production data access.

# Roles and prerequisites

| Role | Responsibility |
| --- | --- |
| Author | Supplies the source and resolves findings |
| Reviewer | Checks content, layout, accessibility and format behavior |
| Coordinator | Verifies approval and packages the exact reviewed files |

Before starting, obtain the approved source, the intended reader and purpose, the requested formats, and the destination. If a required fact is missing, keep it visibly unresolved. Do not invent an approval, date, amount, or signatory.

# Procedure

1. Identify the document family and record why it fits the reader's task.
2. Generate the requested file types from their supported model. Keep the editable source beside the delivery copy.
3. Compare extracted text with the approved source. Check numbers, names, qualifiers, links, code, and legal clause labels explicitly.
4. Inspect every rendered page or slide at a readable size. Check table continuations, footnotes, margins, headings, and empty pages.
5. Open editable files in the intended application when available. If native rendering is unavailable, report that limit; package validation is not visual approval.
6. Resolve blocking findings and rerun the affected checks. Preserve the final output hashes.
7. Package only the reviewed versions. Record the reviewer, date, scope, and unresolved limitations.

# Exceptions and stop conditions

Stop if source text is lost, a number changes, an unsupported component disappears, or a required approval is missing. A generator error is not permission to flatten the document into an image.

For a prescribed regulator, grant, court, or procurement template, use the issuer's current template and instructions. Do not restyle it into a branded report.

# Records and revision history

| Record | Minimum content |
| --- | --- |
| Review record | Source hash, output hashes, criteria, findings and disposition |
| Handoff note | Destination, exact files, approval scope and remaining limitations |
| Revision entry | Version, changed behavior, author and review date |

This draft has no effective date or training sign-off. Those fields must be supplied by the responsible owner before operational adoption.
